Databricks Sales Pipeline

End-to-end Data Engineering project designed to build a scalable sales data platform using Databricks, Apache Spark and Delta Lake. The solution follows the Medallion Architecture pattern (Bronze, Silver and Gold layers), implementing data ingestion, transformation, data quality validation and analytical modeling.

Architecture & Data Pipeline

  • Bronze Layer: Raw data ingestion using Delta Lake with schema enforcement and ingestion metadata.
  • Silver Layer: Data cleansing, business rules validation, deduplication and quarantine process for inconsistent records.
  • Gold Layer: Dimensional modeling with fact and dimension tables optimized for analytical consumption.

Technical Implementations

  • Databricks Workflows for pipeline orchestration
  • Apache Spark and PySpark transformations
  • Delta Lake tables and ACID transactions
  • Incremental data processing
  • Data Quality Framework
  • Quarantine Pattern for invalid records
  • Dimensional Modeling (Star Schema)
  • Delta Lake optimization using OPTIMIZE
  • Materialized Views for analytical workloads
