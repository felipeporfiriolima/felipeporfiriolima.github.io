Databricks • Engenheiro de Dados

Databricks Sales Pipeline

Projeto completo de Engenharia de Dados desenvolvido utilizando Databricks, Apache Spark e Delta Lake. A solução implementa uma arquitetura Medallion (camadas Bronze, Silver e Gold) para ingestão de dados, processamento, validação de qualidade, aplicação de regras de negócio e disponibilização de dados analíticos.

Arquitetura e Pipeline de Dados

  • Camada Bronze: ingestão dos dados brutos utilizando Delta Lake, mantendo histórico e rastreabilidade das informações.
  • Camada Silver: tratamento, padronização, validações de qualidade, aplicação de regras de negócio e processo de quarentena para dados inconsistentes.
  • Camada Gold: modelagem dimensional utilizando tabelas fato e dimensão para consumo analítico.

Implementações Técnicas

  • Arquitetura Medallion (Bronze, Silver e Gold)
  • Armazenamento utilizando Delta Lake
  • Processamento Incremental de Dados
  • Framework de Qualidade de Dados
  • Padrão de Quarentena para registros inconsistentes
  • Modelagem Dimensional (Star Schema)
  • Otimização de Tabelas Delta utilizando OPTIMIZE
  • Materialized Views para consultas analíticas

Tecnologias Utilizadas

Databricks | Apache Spark | PySpark | Delta Lake | SQL | Python | Delta Live Tables

Python • Engenheiro de Dados + IA Engenharia (RAG/LLM)

Pipeline de Engenharia de Dados para Busca Semântica e Aplicações com RAG

Projeto desenvolvido em Python para ingestão, tratamento e indexação de Ordens de Serviço em um banco vetorial utilizando ChromaDB. A solução transforma informações operacionais em conhecimento pesquisável por modelos de IA Generativa (LLMs), permitindo consultas semânticas sobre históricos de atendimento, pareceres técnicos e documentos anexos.

Implementações Técnicas

  • Extração de dados a partir do SQL Server
  • Processamento e padronização de Ordens de Serviço
  • Chunking semântico para documentos extensos
  • Geração de embeddings utilizando modelo multilingual-e5-base
  • Indexação vetorial utilizando ChromaDB
  • Metadados estruturados para filtros inteligentes
  • Processamento de anexos PDF, Word, Excel e CSV
  • Preparação da base para arquitetura RAG (Retrieval-Augmented Generation)
  • Pesquisa semântica para consumo por LLMs

Arquitetura da Solução

SQL Server → Python ETL → Chunking Semântico → Embeddings → ChromaDB → LLM / RAG

Tecnologias Utilizadas

Python | ChromaDB | Embeddings | RAG | LLM | SQL Server

Databricks • Engenharia Avançada em Delta Lake & Otimização

Projeto de Engenharia de Performance utilizando Databricks e Delta Lake

Este projeto demonstra técnicas avançadas de otimização Delta Lake utilizando Databricks e Apache Spark, com foco na melhoria de performance de workloads analíticos em um ambiente Lakehouse. A solução simula desafios reais de Engenharia de Dados, como o problema de Small Files, varredura ineficiente de dados e necessidade de otimização de consultas.

Funcionalidades implementadas

  • Compactação de arquivos Delta Lake utilizando OPTIMIZE
  • Organização dos dados utilizando ZORDER
  • Melhoria do Data Skipping para consultas com filtros específicos
  • Benchmark de performance antes e depois das otimizações
  • Delta Time Travel e restauração de versões históricas para recuperação e auditoria de dados

Arquitetura da Solução

Geração de Dados → Delta Table → Otimização → Performance → Governança

Tecnologias

Databricks | Delta Lake | Apache Spark | PySpark | Spark SQL | Python
